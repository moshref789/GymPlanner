# Gym Program Planner

Gym Program Planner is a web application designed to help users create, customize, and manage their workout programs in a simple and organized way.

The system allows users to register, log in, manage their personal workout schedules, view exercise videos, and customize their account settings.

## Overview

Gym Program Planner helps users build a personalized fitness experience by allowing them to organize workout days, select exercises, and access related exercise videos.

The website provides an easy-to-use interface for managing workout programs and viewing useful fitness information in one place.

## Features

- User registration and login system
- Workout program customization
- Training day organization
- Exercise video selection
- Muscle group diagrams for exercise guidance
- User account settings customization
- Simple navigation between website pages
- Search functionality

## How to Use

1. Register a new account.
2. Log in using your email and password.
3. Go to the My Programs page.
4. Create or customize your workout schedule.
5. Select exercises for each training day.
6. View related exercise videos.
7. Update your account settings when needed.
